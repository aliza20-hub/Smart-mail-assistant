### 📧 Smart Mail Assistant

A full-stack AI-powered email assistant built with **Svelte** and **Spring Boot**, integrating the **Google Gemini API** to analyze incoming emails and generate context-aware replies. The application can identify the email's intent and suggest responses in different tones such as **professional, friendly, concise, or formal**.

**Tech Stack:** Svelte, Java, Spring Boot, REST APIs, Google Gemini API

**Key Features:**

* AI-generated email replies based on message context
* Tone selection for personalized responses
* Spring Boot REST API for AI integration and request processing
* Svelte-based responsive interface
* Secure server-side handling of Gemini API credentials
* Modular architecture separating frontend, backend, and AI services
